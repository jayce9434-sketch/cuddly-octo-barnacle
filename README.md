# MOLT: ZERO

A self-contained bug action roguelite built for GitHub Pages and mobile browsers.

## Core Loop

Each run is 12 chambers. Chamber objectives rotate between hunter purge, brood rescue, chitin vault destruction, marked hunts, rupture races, and apex predator fights. Every cleared chamber offers a mutation draft that changes the player's abilities and visible body.

There is no permanent upgrade currency. Run Chitin is intentionally temporary and is spent only inside the current run on mutation rerolls and shell repair, preventing the late-game dead-currency problem.

## Playable Bugs

- Mantis: melee scythe strikes and pounce Molt ability.
- Moth: ranged scale bursts and radial phase-wing Molt ability.
- Stag: heavy horn combat and defensive shockwave Molt ability.

## Controls

Desktop:
- WASD or Arrow Keys: move
- J or X: strike
- Space or K: dash
- L or C: Molt ability when charge is full
- E: interact with captives
- Pointer/tap in the arena: aim and strike

Mobile/iPad:
- On-screen directional pad
- STRIKE, DASH, MOLT, and USE buttons

## Systems

- 30 discoverable mutations
- 12 standard enemy species
- 3 apex predators
- 5 rotating non-boss objective types
- Procedural hazards
- Genome Codex
- Local save data
- Save export/import
- 0-20,000% Master, Music, and SFX settings
- Reduced flash and screen shake options
- Offline-capable PWA files
- Owner control panel protected by an access code
